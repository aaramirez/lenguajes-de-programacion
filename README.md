# Lenguajes de programación

Cómo se diseña y se define un lenguaje: sintaxis, alcance, cálculo lambda, semántica operacional y denotacional, sistemas de tipos con inferencia de Hindley-Milner, continuaciones, efectos, objetos y macros, construyendo con un intérprete un lenguaje pequeño propio, Ceiba.

**Ver en línea:** https://aaramirez.github.io/lenguajes-de-programacion/
